# AGENTS.md — правила совместной работы ИИ-агентов Андрея

Этот репозиторий — **координационный хаб** командных агентов: ZCode, Codex, Claude Code и Ева (Hermes Agent, hermes-gateway на московском VPS). Цель: каждый агент видит, что делают остальные.

## Обязательные правила

1. **Прочитай перед началом работы:** последние записи `WORKLOG.md` и `git log --oneline -15`.
2. **После значимых изменений** — добавь запись в `WORKLOG.md` (сверху, новее — выше) и закоммить:
   - формат записи: `## ГГГГ-ММ-ДД ЧЧ:ММ — [агент] заголовок`, ниже 1–5 строк сути (что/где/зачем);
   - prefix в сообщении коммита: `[zcode]`, `[codex]`, `[claude]`, `[eva]`.
3. **Секреты не коммитить никогда**: ключи, UUID, пароли, токены, IP-порты прод-конфигов остаются на серверах. Здесь — только ссылки, где искать (см. «Карта»).
4. **Перед push — pull**: работаем в main, конфликты разрешает тот, кто второй.
5. Прод-изменения (сервера Андрея) каждый агент делает по своим правилам безопасности (бэкап → валидация → рестарт → проверка) — и обязательно отражает их здесь.

## Учётные записи агентов на этой машине (karab-pc)

Каждый агент ходит на GitHub **только своим ключом** (решение Андрея, 03.11.2026):

- **Claude Code**: ключ `~/.ssh/id_ed25519_github`, вход по умолчанию `github.com`
- **ZCode**: ключ `~/.ssh/id_ed25519_github_zcode`, персональный вход `github-zcode` в `~/.ssh/config`. Свои репозитории: `git config core.sshCommand "ssh -i ~/.ssh/id_ed25519_github_zcode -o IdentitiesOnly=yes"` или клонирование через `git@github-zcode:…`. Ключ ZCode из общего блока github.com удалён — ходить чужим ключом невозможно.
- **Новый агент** = новый ключ + свой Host-алиас по этому же образцу (иначе ssh возьмёт первый сработавший ключ из config — атрибуция собьётся).
